# Security Policy

## Supported Scope

This repository contains security-sensitive smart contracts and deployment
scripts. Vulnerability reports are welcome for:
- Solidity contracts in `contracts/`
- Upgrade/deployment flows in `scripts/`
- ZK proof wiring and distributor integration

## Reporting a Vulnerability

Do not open a public issue for suspected vulnerabilities.

Send a private report with:
- Affected files and functions
- Impact summary
- Reproduction steps or proof of concept
- Suggested remediation (if known)

Use the maintainer security contact channel configured for this repository.

## Response Expectations

- Initial acknowledgment target: within 72 hours
- Status updates: as investigation progresses
- Public disclosure: coordinated after patch/deployment

## Out of Scope

- Issues in third-party dependencies without project-specific exploitability
- Vulnerabilities requiring leaked private keys from external systems
